# 表格与办公文档

## 表格管理规约（硬性）

- 一律以 CSV 为工作格式：建表、改数、查数都直接用 read/edit/write 工具操作 .csv 文件。
- 编码 UTF-8 带 BOM（写文件时首字符加 ﻿），否则 Excel 打开中文乱码。
- 首行必须是表头；单元格含逗号或换行时整格用双引号包裹，格内双引号写成两个。
- 只有在最终交付给用户时才转 .xlsx，中间过程始终保持 CSV。

## xlsx 导出工具

```
xlsx(sources=[{csv:"数据.csv", name:"明细"}, {csv:"汇总.csv", name:"汇总"}], out:"交付.xlsx")
```

- sources 每项一个 CSV 转成一个工作表，name 为工作表名（简短中文）。
- 多表交付时按"汇总在前、明细在后"排 sources 顺序。
- 转换后向用户报告输出路径和各表行数。

## 数据处理套路

- 统计聚合用 shell 工具跑简短脚本，优先系统自带能力（PowerShell 的 Import-Csv / Group-Object / Measure-Object，或 python 单行脚本），不安装任何依赖。
- 大 CSV（超过几百行）不整读：先 read 前 20 行看结构，再写脚本处理，脚本输出结果到新 CSV。
- 修改数据前先备份原文件为 xxx.bak.csv。
- 涉及金额、数量的汇总，脚本跑完抽 2-3 行手工核对再报结果。

## 数据报告

流程：CSV 统计出结果 → 复制本目录 templates/report.html → 只替换其中 `const REPORT = {...}` 数据对象 → 交付单文件 HTML。

REPORT 结构：title/date/summary、metrics 指标卡片、charts 图表数组、tables 表格数组、conclusions 结论。图表由模板用内联 SVG 渲染，只需填数据：

- bar 柱状：labels 与 values 等长；适合分类对比，超过 12 类先合并小项为"其他"。
- line 折线：labels 为时间序列；适合趋势，点数超过 30 先按周/月聚合。
- pie 饼图：适合占比，类别不超过 6 个，值会自动算百分比。

模板内三种图的 SVG 生成要点（已实现，改样式时参考）：柱状用 rect 按 值/最大值 定高；折线用 polyline 把点映射到坐标系并画圆点；饼图用 path 的 arc 命令按累计角度切扇形，大于 180 度的扇形 large-arc-flag 置 1。

## 周报格式

标题"姓名/团队 周报（M月D日-M月D日）"。三段式：本周完成（3-6 条，每条以动词开头并带量化结果）、下周计划（2-4 条）、风险与求助（没有则写"无"）。每条一行，不写过程只写结果。

## 总结格式

开头一段说清"做了什么、结果如何"（不超过 100 字）。正文按"背景-做法-结果-反思"四节，结果一节必须有数字对比。篇幅控制在 800 字内。

## 公文与信函格式

- 通知/公告：标题（发文单位+事由+文种）、称呼、正文（缘由-事项-要求，事项分条列出）、落款（单位+日期，右对齐）。
- 商务信函：称呼顶格加冒号；首段一句话点明来意；中段分条陈述；末段明确期望动作与时限；结尾"此致 敬礼"分两行，落款署名与日期。
- 用语克制平实，不用感叹号，不用网络用语，日期写全"2026年7月13日"。
