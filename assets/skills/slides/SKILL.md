# 幻灯片制作

产出物：一个自包含 HTML 文件，浏览器全屏播放即投影，打印即导出 PDF 交付。

## 流程（严格按序）

1. 列大纲：每页一句话主旨，写成列表给用户确认。页数 = 讲述时长(分钟) 左右，路演 10-15 页，课件可更多。
2. 定版式：给每页从版式清单里挑一种，标注哪些页需要插图。
3. 先生图：需要插图的页，逐张调用 image 工具生成，存到与 HTML 同目录的 assets/img/ 下，文件名如 img-03（编号对应页码，扩展名以工具返回的真实格式为准）。配图页数按用户要求的最大解释执行：「封面和至少 2 页配图」= 封面之外再配 2 页、共 3 张起，宁多勿少。
4. 出成品（二选一，鼓励前者）：
   - 自由设计：自写整个 deck.html，版式、配色、动效自定，追求内容丰满与视觉记忆点；templates/deck.html 仅作翻页交互、打印样式、页码指示的实现参考。
   - 套模板：赶时间或要求极简时，复制 templates/deck.html 只改 `const SLIDES = [...]` 数据。
5. 无论哪种方式必须保住的底线：单文件零外链、方向键+点击翻页、页码指示、明暗自适应、@media print 每页一张横版。
6. 自检：浏览器打开翻一遍，确认无空页、图片路径正确、每页文字不溢出。

## 投影式原则（硬性）

- 一屏一意：一页只讲一件事，讲不完就拆页。
- 每页核心文字不超过 3 行，每行不超过 20 字。逐字稿放 note 字段（演讲者备注），不上屏。
- 大字号、大留白。宁可空，不可挤。
- 数据用大数字版式（big）呈现单个关键数字，禁止贴表格截图；多组数据才用对比页。
- 标题是观点句（"成本下降 40%"），不是话题词（"成本分析"）。

## 生图配合规范

- 全套 PPT 只用一种插画风格。先定一句风格词缀，每张 prompt 都以它结尾，例如："扁平插画风格，墨蓝主色调，简洁留白，商务风"。
- 比例一律 16:9。
- prompt 末尾加"画面中不要出现任何文字"，避免生成乱码文字。
- prompt 写具体画面（主体+场景+氛围），不要抽象概念词。
- 生成失败或无 image 工具时，img 留空字符串，模板会显示渐变占位块，不影响交付。

## 版式清单（type 取值）

- cover 标题页：title 主标题，points[0] 副标题/演讲人/日期
- section 章节页：title 章节名，points[0] 可选一句引导语
- points 要点页：title + points（最多 3 条，每条一短句）
- big 大数字页：big 放数字或短语（如 "3.2 亿"），title 放结论句
- compare 对比页：left/right 各含 title 与 points，左右并列
- image 图文页：img 图片相对路径 + title + points（最多 2 条）
- quote 引言页：quote 引文，title 放出处
- end 结尾页：title 收束语，points[0] 联系方式或行动号召

每页均可附 note 字段写演讲备注。数据结构示例见模板内置的 8 页示例。

## 播放操作（告知用户）

方向键/空格/点击翻页，Esc 缩略图总览，N 显示备注，Ctrl+P 打印导出 PDF。
